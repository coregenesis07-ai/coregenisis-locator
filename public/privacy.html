Privacy Notice / Aviso de Privacidad

Effective: October 3, 2026

Current status: New alert enrollment is temporarily paused while we improve verification, consent, deletion, retention, and abuse-prevention controls.

Information used by the site

The inmate-search feature sends search information needed to retrieve publicly available Federal Bureau of Prisons locator information. The alert system was designed to use a BOP register number, inmate name, subscriber email address, language preference, facility/release information, and timestamps. The prior design also included an optional telephone field; new telephone collection is paused and SMS is not currently offered.

Why information is used

Search information is used to return custody-locator results. Alert information, when the alert service is available, is intended only to monitor requested public BOP information and deliver requested change notices.

Service providers and sources

The application uses Cloudflare infrastructure and D1 database technology. It retrieves public locator information from BOP.gov. The alert code is designed to use an email-delivery provider to transmit requested alerts. These providers may process the information necessary to provide those functions.

No sale statement

The reviewed application code does not contain advertising pixels or code designed to sell subscriber information. This statement describes the reviewed code and does not replace a review of production vendor settings.

Retention and control

We are reviewing and documenting a defined retention schedule. Until the alert service is relaunched with appropriate controls, new alert enrollment is paused. A self-service deletion and unsubscribe process will be provided before new alert enrollment resumes.

Children

Federal Custody Guide is a general-audience educational service and is not directed to children under 13. Do not submit personal information through alert features for a child under 13.

Security

We use reasonable technical and organizational measures appropriate to the service, but no Internet service can guarantee absolute security.

Government independence

Federal Custody Guide is an independent educational resource. It is not affiliated with or endorsed by the Federal Bureau of Prisons or another government agency.

Contact and privacy requests

Before publishing a contact address here, the site operator is confirming the correct business/privacy contact. In the meantime, new alert enrollment remains paused so this notice does not invite collection without a functioning request channel.

Important limitations

Do not submit information that is not necessary to use the requested feature. Public BOP information may concern other people. Users are responsible for using the service lawfully and appropriately. This notice describes the site's reviewed implementation; production infrastructure or vendor settings must be reviewed before any new data-collection feature is activated.

Changes to this notice

We may update this notice when the service or its data practices change. The effective date above should be updated when material changes are published.

Información utilizada

La búsqueda utiliza la información necesaria para consultar información pública disponible del localizador del BOP. Si las alertas se reactivan, el sistema está diseñado para utilizar el número de registro BOP, nombre, correo electrónico del suscriptor, preferencia de idioma, información de instalación/liberación y marcas de tiempo necesarias para prestar el servicio solicitado.

Propósito y proveedores

La información de búsqueda se utiliza para devolver resultados públicos de custodia. La infraestructura técnica y proveedores necesarios pueden procesar información para prestar esas funciones. La información importante debe verificarse con BOP.gov.

Venta y publicidad

El código revisado no contiene píxeles publicitarios ni código diseñado para vender información de suscriptores. Esta declaración describe el código revisado y no sustituye la revisión de la configuración real de proveedores antes del lanzamiento.

Retención y control

Todavía estamos documentando un período definido de retención. Las nuevas alertas permanecerán pausadas hasta que exista un proceso funcional de cancelación y eliminación y se complete la información de contacto para solicitudes de privacidad.

Menores y seguridad

El servicio es de audiencia general y no está dirigido a menores de 13 años. No envíe información personal de un menor de 13 años mediante funciones de alertas. Utilizamos medidas razonables apropiadas para el servicio, pero ningún servicio de Internet puede garantizar seguridad absoluta.

Independencia y limitaciones

Federal Custody Guide es un recurso educativo independiente y no está afiliado ni respaldado por el BOP u otra agencia gubernamental. No envíe información innecesaria. Los usuarios son responsables de utilizar la información pública de manera legal y apropiada.

Cambios y contacto

Este aviso puede actualizarse cuando cambie el servicio o sus prácticas de datos. Antes de publicar una dirección de privacidad, el operador está confirmando el contacto comercial correcto. Las alertas permanecerán pausadas mientras no exista un canal funcional para estas solicitudes.
